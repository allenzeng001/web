# Personal site

Pixel-art sea theme, built with Next.js.

- Edit text and links: `data/site.js`, `data/top5s.js`, `data/projects.js`
- Resume: replace `public/resume.pdf`
- Project downloads: add files to `public/downloads/`, then list them in `data/projects.js`
- Photography link: set `photographyUrl` in `data/site.js`

Run locally: `npm install && npm run dev`
